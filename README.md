# Hermes personal information site

Static homepage and privacy policy for Miguel Rodrigues’s personal Google OAuth app, named Hermes. Not an official Nous Research website.

## Publication

GitHub Pages serves the main branch at its repository root. There are no dependencies, JavaScript, analytics, OAuth endpoints, or credentials in this repository.

- Home: https://miguelrodriguesquack.github.io/hermes-personal/
- Privacy: https://miguelrodriguesquack.github.io/hermes-personal/privacy.html

## Maintenance

Keep the privacy policy consistent with actual permissions, data use, retention, and configured providers. Currently disclosed scopes: calendar.events.owned and gmail.send. Do not publish tokens, account data, private task captures, or Trello Inbox addresses.

The Google Cloud console accepting these URLs and any domain verification are separate from deploying this website; deployment is not proof of Google approval.

## Checks

Check HTML parsing, local navigation targets, absence of scripts and forms, and successful public HTTP responses for both pages after each deployment.
